# DF26 Web 0.3.0 · 简化连接、调试与 OTA

主页面直接进入机器人调试，默认打开马达测试，另外两项为配网与 OTA。OTA 按步骤显示按钮，管理密码、手动 IP 和更新通道进入管理设置。

配合固件 2.2.0：首次连接提示管理密码，使用 Web Crypto 加密后保存在 IndexedDB；支持中文设备名、热点与管理密码同步修改；优先通过 BLE 发起 ESP32 在线下载，失败后可切换热点升级。浏览器提供系统 Wi-Fi 连接指引，核对设备身份后才上传，重连核对版本后报告完成。

修复 PWA 缓存设备 API / 固件清单的问题。API 请求直接访问网络；校验后的离线固件继续保存在专用 IndexedDB 缓存。

验证：17 项设备与升级流程测试、桌面和手机宽度下的实际页面交互、加密凭据存储及模拟 OTA 全流程。浏览器不直接切换电脑 Wi-Fi，真实机器人仍需验收。
